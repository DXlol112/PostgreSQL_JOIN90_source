# Проверка комплекта исходников

- Код сервера, SQL-движок, задания и интерфейс сохранены из подготовленной
  Linux-версии; при упаковке нормализованы переводы строк.
- В отдельной копии проекта с PGlite 0.5.17 выполнены 37 интеграционных
  проверок через `node scripts/test.mjs`; все проверки пройдены.
- Проверены все 29 эталонных тестов заданий, сохранение, письменные ответы,
  сброс оценки при изменении ответа, выполнение и отмена SQL, экспорт ZIP.
- Исходники Go-запускателя успешно собраны Go 1.27.4 с GOOS=linux,
  GOARCH=amd64 и CGO_ENABLED=0. Результат проверен как статический ELF x86-64.
- Проверены синтаксис JavaScript/Python, JSON, настройки исключений Git,
  состав папки и отсутствие локальных пользовательских путей.
- Функциональные проверки выполнялись в Windows с Node.js 22.23.5.
  Непосредственный запуск в Linux и полный сценарий сборки в Linux
  при подготовке комплекта не выполнялись.
- Зависимости для локальной проверки взяты из предоставленного
  Windows-дистрибутива. Чистая установка через npm здесь не выполнялась;
  исходный package-lock.json сохранён для `npm run setup`.
