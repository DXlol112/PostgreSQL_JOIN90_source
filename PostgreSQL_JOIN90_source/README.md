# PostgreSQL JOIN90

Восстановленная версия учебного тренажёра PostgreSQL JOIN для Linux x64: 12 заданий, 7 разделов теории, запуск SQL на учебной базе, автопроверка, сохранение работ и сдача результатов в ZIP.

Исходники оригинального Go-сервера не были предоставлены. В этой версии локальный сервер написан заново на Node.js, а интерфейс, редактор, задания, тестовые наборы и SQL-движок извлечены из предоставленного Windows-дистрибутива. Нативный Linux-запускатель написан на Go.

## Запуск из исходников

Требуются Node.js 22+ и npm. Сервер PostgreSQL устанавливать не нужно.

```bash
npm run setup
npm start
```

Откройте полный адрес из терминала, включая `#token=...`, если браузер не открылся автоматически. Программа слушает только `127.0.0.1`. Для автоматического открытия браузера в Linux используется `xdg-open`.

После установки зависимости программа работает без интернета. Запуск через Node.js доступен и в Windows; Go-запускатель предназначен для Linux.

Параметры передаются после `--`:

```bash
npm start -- -no-open
npm start -- -port 8080
npm start -- -data-dir ./data
npm start -- -version
```

По умолчанию работы сохраняются в `${XDG_DATA_HOME:-$HOME/.local/share}/PostgreSQLJoin90/workspaces`. Для завершения используйте Ctrl+C или кнопку «Завершить работу». Кнопка «Сдать работу .zip» выгружает ответы, письменные объяснения и отчёт с результатами.

## Сборка автономного архива для Linux x64

Скрипт запускается в Linux x86_64 с glibc. Нужны Bash, Go 1.27+, Node.js 22+, npm, curl, tar и sha256sum. При сборке интернет используется для установки PGlite и загрузки официального Node.js 22.23.5; SHA-256 дистрибутива проверяется.

```bash
npm run build:linux
```

Результаты:

```text
dist/PostgreSQL_JOIN90_Linux_x64.tar.gz
dist/PostgreSQL_JOIN90_Linux_x64.sha256
```

Для запуска готового архива:

```bash
tar -xzf PostgreSQL_JOIN90_Linux_x64.tar.gz
cd PostgreSQL_JOIN90_Linux_x64
./PostgreSQL_JOIN90
```

Архив включает Node.js, PGlite и все материалы. Для запуска нужны Linux x86_64, glibc 2.28+, `libstdc++.so.6` с `GLIBCXX_3.4.21` / `CXXABI_1.3.9`, стандартные системные библиотеки и современный браузер. Go и npm на целевом компьютере не нужны.

Сборка только запускателя:

```bash
cd launcher
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath \
  -ldflags='-s -w -buildid=' -o ../PostgreSQL_JOIN90 .
```

Запускатель ожидает `runtime/node` и остальные файлы приложения рядом с собой. Полный комплект формирует `scripts/build-linux.sh`.

## Проверки

Для интеграционных проверок дополнительно требуется Python 3:

```bash
npm run setup
npm test
```

Проверяются все 29 эталонных тестов заданий, выдача материалов, ограничения SQL, письменные ответы, сохранение после перезапуска, сброс результата при редактировании, отмена запроса и целостность ZIP. Тесты создают временную папку и не используют сохранённые работы пользователя.

Если Python установлен под другим именем, задайте переменную `PYTHON` или запустите тест напрямую:

```bash
python3 tests/smoke_test.py --node /путь/к/node
```

Функциональные проверки этой версии выполнялись в Windows с Node.js 22.23.5. Linux-запускатель был собран кросс-компиляцией и проверен как ELF x86-64. Непосредственный запуск в Linux при подготовке исходников не выполнялся.

## Структура

```text
app/server.mjs             Локальный HTTP-сервер, работы и экспорт ZIP
web/                      Интерфейс и редактор
content/pg_join.json       Задания, теория и эталонные результаты
content/pg_fixtures.json   Наборы данных для проверки SQL
runtime/engine.mjs        SQL-движок на PGlite
runtime/package*.json     Зафиксированная зависимость PGlite 0.5.17
launcher/                 Исходники нативного Linux-запускателя
scripts/                  Сборка и запуск тестов
tests/                    Интеграционные проверки и тестовые решения
training_database.sql     Учебная база для внешнего PostgreSQL
THIRD_PARTY.md            Происхождение компонентов
```

Содержимое `node_modules`, готовые исполняемые файлы, результаты сборки, локальные работы и временные файлы исключены через `.gitignore`. Исходные материалы курса и тестовые решения входят в репозиторий.
